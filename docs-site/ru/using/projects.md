# Проекты и доступ

**Проект** объединяет связанные задачи и решает, кто их видит и запускает.
Каждая задача принадлежит одному проекту, а у каждого проекта свой системный
промпт, список доступа и журнал активности.

## Создание проекта

Откройте **Projects → New project** и заполните:

- **Имя и slug** — slug используется в id задач и URL.
- **Описание** — краткое резюме для списка.
- **Команды** — команды с доступом и их роли.
- **Промпт** — системный промпт проекта, добавляемый каждой задаче.

Проект приватн для владельцев, пока вы не привяжете команду или не выдадите
роль отдельному актору.

## Роли

| Роль | Что может |
| --- | --- |
| **Owner** | Управлять проектом, доступом, промптом и настройками; создавать задачи и писать промпты. |
| **Member** | Создавать задачи и писать промпты в проекте. |
| **Viewer** | Читать задачи, логи и артефакты, но не создавать и не писать промпты. |

Эффективная роль актора — сильнейшая из:

1. прямого гранта на проект;
2. лучшей роли среди команд, в которых состоит актор и которые привязаны к
   проекту.

Администраторы обходят правила проекта. Агенту тоже нужна роль: он получает
задачи проекта, только имея её.

## Команды

Привяжите команду во вкладке **Access**, выберите роль и подтвердите. Участники
команды наследуют роль. Отзыв команды немедленно убирает доступ её участникам.

Если команда приглашает проект к сотрудничеству, владелец любой стороны
одобряет приглашение. Ожидающие приглашения видны в инбоксе agency.

## Промпты

CherryPi собирает системный промпт задачи из четырёх слоёв:

1. organization;
2. agent;
3. project;
4. agent × project.

Промпт проекта — лучшее место для конвенций репозитория, правил деплоя и всего,
что должно применяться ко всем задачам проекта. Промпты версионируются; задача
фиксирует версии на момент старта, поэтому редактирование промпта не
переписывает историю.

## Настройки проекта

Владельцы меняют:

- имя, slug и описание;
- доступ (команды и прямые гранты);
- промпт проекта;
- теги задач;
- архивирование и удаление.

Удаление проекта удаляет его задачи и артефакты. Сначала сохраните всё нужное.
Если удаление проектов разрешено только администраторам, даже владельцы
обращаются к ним.
