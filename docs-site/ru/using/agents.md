# Агенты

**Агент** — зарегистрированный воркер. Agency показывает его присутствие,
версию, задачи, использование и логи; работа происходит на машине агента.

## Список агентов

![Список агентов с присутствием, версией и формой регистрации](/screenshots/agents-list.png)

Список показывает агентов, которыми вы владеете или которые доступны через
команду. В строке:

- **Присутствие** — online, offline или недавно отключён;
- **Версия** — сборка агента и версия протокола;
- **Задачи** — текущая и недавняя работа;
- **Владелец** — кто может управлять.

**Register agent** создаёт нового. Agency показывает одноразовый personal
access token. Скопируйте его в `CHERRYPI_AGENT_TOKEN` (или передайте
`--token pat_…`). Username/password tunnel-креденшела нет.

## Страница агента

![Страница агента с вкладками, статусом online и списком задач](/screenshots/agent-detail.png)

| Вкладка | Что показывает |
| --- | --- |
| **Overview** | Идентичность, присутствие, статистика хоста, текущие задачи и активность. |
| **Usage** | Токены и стоимость задач агента. |
| **Terminals** | Root PTY на машине агента. Владельцы открывают терминалы; остальные наблюдают. |
| **RDP** | X-дисплей агента, если задан `DISPLAY`. |
| **Logs** | Process-лог агента с фильтрами по жизненному циклу и подключению. |
| **Settings** | Имя, описание, аватар, значения по умолчанию, владельцы, лимиты и токены. |

**Logs** — первое место при offline-агенте или упавшем старте задачи. Там
версия при запуске, строки connect/disconnect туннеля, жизненный цикл задач и
ошибки.

## Владение и роли

Создание агента делает вас первым владельцем. Владельцы редактируют агента,
одобряют приглашения в команды, управляют владельцами и открывают root-
терминалы. Администраторы управляют всем парком.

Агент может быть **member** или **admin**. Admin-агент — наблюдатель только на
чтение логов и метаданных парка; роль меняет только человек-администратор.

## Лимиты параллельности

**Settings → Limits** на агенте задаёт, сколько задач он выполняет:

- общий лимит;
- лимит на проект;
- переопределения по тегам и тегам проекта.

Планировщик берёт queued-задачи, пока есть свободный слот. Значения по
умолчанию консервативны; поднимайте их, когда у хоста есть запас и провайдер
модели выдерживает нагрузку.

## Токены

**Settings → Security → Personal access tokens** на агенте показывает,
выпускает и отзывает PAT. Токен — единственный креденшел агента:

```sh
CHERRYPI_AGENT_TOKEN=pat_…
# или
cherrypi-agent --agency-url … --token pat_…
```

Явный токен важнее кэшированного файла. Ротируйте токен, выпуская новый и
перезапуская агента, либо заменяя `$CHERRYPI_DIR/agent.token` (инструменты Pi
перечитывают его).

## Удаление агента

Удаление агента убирает его токены и доступ. Задачи остаются в agency и
могут быть переназначены. Убедитесь, что на агенте не выполняется задача.
